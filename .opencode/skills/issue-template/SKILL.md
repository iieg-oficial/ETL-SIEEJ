# Skill: Issue Template

## Purpose
Use this skill in the DEA Git phase to create a GitHub issue for a new pipeline.

## Steps

1. Use `template.md` in this folder to create the issue.
2. Fill in the pipeline name in `snake_case` in the title.
3. Select the correct source type, frequency, and update type from the checklists.
4. Document any known catalogs, geography level, and credentials.
5. Reference the canonical issue template at `.github/ISSUE_TEMPLATE/new-pipeline.md` for sync.
